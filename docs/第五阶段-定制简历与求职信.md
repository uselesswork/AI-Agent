# 第五阶段：定制简历建议稿与求职信

> 第六阶段已增加人工编辑、版本保存与核对后导出，见[第六阶段说明](第六阶段-人工编辑与草稿版本.md)。本页记录第五阶段自动草稿能力及其验证范围。

## 一眼看懂本阶段

从求职看板中已保存的一条投递记录出发，读取候选人画像、岗位画像和匹配报告，生成可在页面预览的简历建议稿与求职信草稿，并分别下载 DOCX 或 PDF。生成不再调用大模型，也不修改数据库；同一记录的内容随其保存的画像生成。匹配报告中的修改建议单独展示，绝不作为已经发生的经历写入草稿。

## 数据流与真实性边界

1. 用户在 `/upload` 的求职看板选择一条已保存记录，点击“生成定制材料”。
2. 后端通过现有仓储读取 `candidate_profile`、`job_profile`、`match_result` 的保存快照。
3. `draft_composer` 只把候选人画像里的姓名、联系方式、教育、技能、项目、实践和证书组织成草稿；岗位信息只决定目标岗位文字与相关技能/项目的呈现顺序。岗位技能本身不会被写成候选人已掌握技能。
4. 求职信中的“与岗位相关的已记录事实”只选取画像中已存在的教育、技能、项目和实践。若这些字段为空，仅保留基本应聘意向并给出警告。
5. 匹配报告的 `resume_suggestions` 仅出现在页面独立的“修改建议”区域；`strengths`、`gaps`、分数和模型推断不会转成简历事实。
6. 用户点击下载时，根据同一草稿结构现生成文件；不保存生成物、不新增表、不调用 OpenAI 或 DeepSeek。

原始简历和岗位描述正文没有随第四阶段保存到数据库，因此本阶段无法对原文做逐句核验。页面和接口都返回“投递前核对原件”提示；这仍是待人工审核的建议稿，不应直接当成最终投递材料。画像原有的 `warnings` 也会随预览返回。

## 接口

| 方法和路径 | 用途 |
| --- | --- |
| `GET /api/applications/{id}/draft` | 返回 `resume`、`cover_letter`、`suggestions`、`warnings` 预览数据。 |
| `GET /api/applications/{id}/draft/resume.docx` | 下载简历建议稿 DOCX。 |
| `GET /api/applications/{id}/draft/resume.pdf` | 下载简历建议稿 PDF。 |
| `GET /api/applications/{id}/draft/letter.docx` | 下载求职信草稿 DOCX。 |
| `GET /api/applications/{id}/draft/letter.pdf` | 下载求职信草稿 PDF。 |

记录不存在返回 404；参数不在指定类别/格式内返回 422。PDF 导出如找不到中文字体返回 503，需配置环境变量 `PDF_CJK_FONT_PATH` 指向可用的中文 TTF/TTC 字体。Windows 默认尝试系统 Noto Sans SC 或黑体，部分 Linux 安装默认尝试 Noto CJK。DOCX 使用 Word 字体名 `Microsoft YaHei`，其他系统打开时由阅读软件进行字体替代。

## 使用与测试

按根目录 README 启动应用，打开 `http://127.0.0.1:8000/upload`。先保存匹配报告为投递记录，再到“我的求职看板”点击相应卡片的“生成定制材料”，核对预览、修改建议和警告，最后下载所需格式。也可在 `/docs` 中直接调用接口。

在 `D:\Agent\job-agent` 运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check app tests
```

2026-10-21：自动化测试 42 项通过，Ruff 检查通过。新增测试使用临时 SQLite 仓储和人工夹具，验证 DOCX/PDF 文件头、中文文本可解析、草稿事实与建议分离，以及长内容 PDF 自动换页；不代表真实 MySQL 或大模型联调。另对虚构测试简历生成的 PDF 进行页面渲染与目视检查，中文和分区排版正常。DOCX 已做结构与文本测试，但本环境缺少可供文档渲染器使用的 LibreOffice，尚未完成 DOCX 页面级目视核查。原有 MySQL 数据结构没有改动。本阶段未对真实个人简历或招聘信息进行人工事实核查。

## 仍未实现

- 本阶段交付时未提供草稿在线编辑和版本保存；第六阶段已补充。模板切换和一键投递仍未实现。
- 未对结构化画像中的原始证据逐句校验；既有画像如有误，草稿会继承该错误。
- 求职信是基于事实的固定结构草稿，不是新增一次大模型写作调用；需用户自行润色语气并确认个人意愿。
- PDF 字体依赖运行环境，跨平台部署前要安装中文字体或设置 `PDF_CJK_FONT_PATH`。
